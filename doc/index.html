GitHub Build Guide ↓

Overview

Project Architecture

Four modules, two build targets. Core stays stable across seasons — each year's robot is a fork that inherits everything and adds the season-specific code.

🤖

FtcRobotController

Base · untouched

Official FIRST SDK. Never modified. Pulled from upstream each season to stay current.

⚙️

Core

Control Hub

Shared reusable components: gamepad abstraction, alliance management, configuration helpers. Lives as a fork of FTC Controller. Every season project forks Core.

🧪

TeamCode

Control Hub

Temporary test workspace. Used to validate Core components before a season fork is created. Will not persist long-term.

📊

Panels

Build online

Plugins for Panel by Lazar dashboard. Written in Kotlin + Svelte. Compiled separately and deployed as AAR into TeamCode.

Compilation

Build Guide

Two independent pipelines. Panels is compiled first (online / local machine), then the main Android project is pushed to the Control Hub via Android Studio.

📊
Panels online / local
1

Prerequisites

Java 17+, Node.js 20+, and Android SDK must be available on your machine.

2

Install Bun

Panels uses Bun as the JS runtime and package manager.

# macOS
brew install oven-sh/bun/bun

# Windows — winget (recommended)
winget install Oven-sh.Bun

# Windows — PowerShell installer
powershell -c "irm bun.sh/install.ps1 | iex"
3

Install web dependencies

Navigate to the navlet's web folder and install packages with Bun.

cd Panels/AllianceNavlet/web
bun install
4

Build and deploy

The deployToTeamCode Gradle task assembles the AAR and copies it directly into TeamCode/plugin/.

./gradlew :Panels:AllianceNavlet:deployToTeamCode
5

Result

The file TeamCode/plugin/alliance-plugin.aar is ready to be picked up by the Android build.

🤖
Core + TeamCode Control Hub
1

Prerequisites

Android Studio Ladybug 2024.2 or later. Android SDK 30+ and build tools installed.

2

Connect to the Control Hub

Connect via USB or Wi-Fi Direct. The Control Hub appears as an ADB device in Android Studio.

3

Build all modules

Sync Gradle, then run a full build. Panels AAR must already be present in TeamCode/plugin/.

./gradlew assembleDebug
4

Deploy to the hub

Use the Run button in Android Studio targeting the TeamCode module, or push via ADB.

./gradlew :TeamCode:installDebug
5

Start an OpMode

Open the Driver Station app and select the desired OpMode from the list.
